# Supermarket_Data_Analysis
"An end-to-end data analysis project exploring supermarket sales performance, customer behavior, and product trends using Python, PostgreSQL, and Power BI."
Supermarket Sales Data Analysis
Overview
This project provides an end-to-end data analysis of supermarket sales to uncover key business insights. The analysis spans from raw data processing to the creation of interactive dashboards, designed to identify trends, customer behavior, and branch performance.

Datasets
Supermarket Sales Data: Contains transactional information including product lines, customer types, payment methods, ratings, and sales figures.

Tools Used
Python: Used for data cleaning and Exploratory Data Analysis (EDA) in Jupyter Notebooks (Pandas, NumPy).

SQL: PostgreSQL used for querying and performing complex analytical operations.

Power BI: Built interactive dashboards for data visualization and KPI tracking.

Gamma AI: Used for generating professional project presentations.

VS Code: Development environment.

Project Steps
Data Preprocessing: Loaded the dataset in Python to handle missing values and perform data cleaning.

Database Management: Imported cleaned data into PostgreSQL to run analytical SQL queries.

Data Analysis: Executed SQL queries to analyze revenue, branch performance, and customer spending patterns.

Visualization: Developed a Power BI dashboard to visualize trends and key business metrics.

Reporting: Compiled analytical findings into a structured project report and a Gamma AI-generated presentation.

Dashboard Highlights
The interactive dashboard includes:

Revenue Overview: Total sales by branch and product line.

Customer Insights: Member vs. Normal customer spending trends.

Operational Metrics: Peak sales hours and preferred payment methods.

Results
Identified top-performing product lines and branches.

Analyzed the correlation between customer ratings and total sales.

Provided actionable insights for improving branch-wise profitability.

How to Run
Python Analysis: Open Supermarket_Sales_Analysis.ipynb in Jupyter Notebook to view the cleaning and EDA process.

SQL Queries: Run the scripts in Supermarket_Queries.sql within your PostgreSQL environment.

Dashboard: Open Supermarket_Shopping_Dashboard.pbix in Power BI Desktop to interact with the visualizations.
